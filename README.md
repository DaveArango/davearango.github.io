# Signs, Languages & Ideas

Three-page English blog for an academic evidence activity.

- `interpreter.html` — professional journey as an LSC–Spanish interpreter and translator.
- `english.html` — three useful SENA English-learning activities.
- `critical-thinking.html` — critical thinking and media literacy, using misinformation after the August 2026 Colombia earthquake as the case study.
- `style.css` — shared responsive visual design.
- `assets/` — example images supplied in the evidence PDF.

For GitHub Pages, you can rename `interpreter.html` to `index.html` so it becomes the default home page. If you do that, update the navigation links in the three HTML files accordingly.
